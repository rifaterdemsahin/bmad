# BMAD DSL (Domain Specific Language) / Glossary 📖

## Unique Terms & Concepts

---

### 📎 Paperclip Co.
**Definition:** A conceptual one-person company generating billion-dollar revenue, operated entirely by an agentic AI workforce. No human employees. No office. Just an owner, a vision, and a fleet of BMAD agents executing every function from engineering to marketing to customer support.

**Origin:** Inspired by the "paperclip maximizer" thought experiment — but inverted. Instead of an AI optimizing for paperclips at all costs, Paperclip Co. uses AI agents to build a maximally efficient, autonomous enterprise.

**Key Characteristics:**
- **Headcount:** 1 human (the founder/owner)
- **Workforce:** 9+ BMAD agents (Analyst, Architect, CTO, Orchestrator, Transformation, Pipeline, Dashboards, Content, Coach)
- **Revenue Model:** BMAD in a Box licenses + Enterprise consulting
- **Infrastructure:** Serverless, agent-orchestrated, zero manual ops
- **Goal:** Prove that a single human + agentic AI can out-perform traditional 100-person enterprises

---

### 🔄 BMAD-METHOD™
**Definition:** A structured 4-pillar framework for enterprise AI transformation.

| Pillar | Emoji | Focus |
|--------|-------|-------|
| **B**usiness | 💼 | Market strategy, pricing, partnerships, revenue models |
| **M**odel | 📊 | Data models, predictive analytics, AI training pipelines |
| **A**rchitecture | 🏗️ | Systems design, infrastructure, security, compliance |
| **D**esign | 🎨 | UX, ergonomics, human-agent interaction patterns |

**Use:** Every project, document, and agent in Paperclip Co. maps back to one or more BMAD pillars.

---

### ⚡ Hermes
**Definition:** The central orchestrator agent that routes work between the tri-model AI stack (Claude / Company LLM / Local) and coordinates the other BMAD agents.

**Named after:** Hermes, Greek messenger god — because this agent carries messages between models and agents.

**Analogy:** Think of Hermes as the "air traffic control tower" for Paperclip Co.'s AI workforce.

---

### 🧠 Mary (Analyst)
**Definition:** The market intelligence agent. Named "Mary" as a nod to "market research."

**Role:** Competitor analysis, trend spotting, ROI input generation, brainstorming facilitator.

---

### 🏗️ Architect
**Definition:** The systems design agent responsible for technical blueprints, ADRs (Architecture Decision Records), and infrastructure planning.

**Analogy:** The Architect draws the building plans. The CTO approves them. The Pipeline builds them.

---

### 👨‍💼 CTO Agent
**Definition:** An AI agent that plays the role of Chief Technology Officer — approving architecture decisions, setting technical strategy, and assessing risk.

**Why an agent?** In Paperclip Co., there is no human CTO. The agent IS the CTO. It holds the technical veto power.

---

### 🔄 Transformation Agent
**Definition:** The change management agent that guides external enterprises through BMAD adoption.

**Key Output:** `ai-maturity-report.pdf` + `bmad-transformation-roadmap.md`

---

### 🛠️ Pipeline Agent
**Definition:** The CI/CD automation agent. Every time an agent definition is updated, the Pipeline builds, tests, and deploys it.

**Analogy:** If Hermes is air traffic control, Pipeline is the runway crew — making sure every plane (deploy) takes off and lands safely.

---

### 📊 Dashboards Agent
**Definition:** The observability and metrics agent. It asks: "Is the system healthy? Is the business growing? Are agents performing?"

**Key Outputs:** Engineering health dashboard, model latency tracker, business ROI view.

---

### ✍️ Content Agent
**Definition:** The editorial engine. It drafts Substack essays, writes LinkedIn posts, updates GitHub READMEs, and repurposes content across channels.

**Tagline:** "The voice of Paperclip Co."

---

### 🎯 Coach Agent
**Definition:** The accountability and wellness agent. It runs daily check-ins, weekly retrospectives, and tracks goals for the human founder (and eventually, other humans).

**Analogy:** A personal trainer + Scrum Master hybrid that never sleeps.

---

### 🏠 CTO in a Box
**Definition:** A personal AI stack for individual life optimization. The "consumer version" of Paperclip Co.'s enterprise architecture.

**Components:**
- Orchestrator: n8n / Home Assistant
- LLM: Local Ollama
- Memory: Obsidian + Vector DB
- Voice: Whisper + Piper

**Goal:** Save 5 hours/week per person.

---

### 📦 BMAD in a Box
**Definition:** A single deployable package that transforms any enterprise into a BMAD-powered organization in < 1 hour.

**What's Inside:**
- All 9 BMAD agent definitions
- Tri-model architecture templates
- Docker / Terraform / K8s manifests
- Data source JSON templates
- 10-minute setup guide

---

### 🧾 ADR (Architecture Decision Record)
**Definition:** A lightweight document capturing why a particular technical decision was made. Versioned, searchable, and approved by the CTO Agent.

**Format:** `architecture-decision.md` template in Obsidian.

---

### 📬 Substack (in BMAD context)
**Definition:** The primary distribution channel for Paperclip Co.'s thought leadership. Used to build the BMAD practitioner community.

**Hub-and-Spoke Model:** Substack = conversation. BMAD site = proof. Together = pipeline.

---

### 🧠 Obsidian (in BMAD context)
**Definition:** The long-term memory system for the BMAD team. Every agent prompt, architecture decision, and stakeholder interaction is captured in a personal vault.

**Rituals:**
- Morning Brief (auto-generated daily note)
- Agent Prompt Log (every Claude/OpenCode interaction archived)
- Weekly Sync (Friday export to kanban)

---

### 🤖 Agentic AI
**Definition:** AI systems that operate autonomously with defined roles, goals, and workflows — not just chatbots that respond to prompts.

**BMAD Definition:** An agent has:
1. A persona (name, role, style)
2. Commands (actionable instructions)
3. Integration (wires into a system or workflow)
4. Accountability (can be tracked, measured, improved)

---

### 📎 Control Manifest
**Definition:** A governance document that allows human developers to actively steer AI co-pilots through a governed pull request lifecycle.

**Purpose:** Prevents the "Old Abstraction Trap" where prompts enter a black box and produce untraceable, high-risk code.

---

### 📋 Kanban (in BMAD context)
**Definition:** The public task board tracking all Paperclip Co. initiatives. Transparent, drag-and-drop, and embedded in the BMAD site.

**Philosophy:** "If it isn't on the kanban, it doesn't exist."

---

### 🔄 Continuous Compliance Ledger
**Definition:** An auditable, versioned record of every decision, change, and approval in the BMAD system. The "receipt" for enterprise governance.

**Output:** Auto-generated from PR history + ADRs + agent decision logs.

---

### 🎯 One-Person Billion-Dollar Company (OPBDC)
**Definition:** The aspirational model behind Paperclip Co. — proving that with agentic AI, a single human can architect and operate an enterprise-scale business.

**Math:**
- 1 human × 9 agents × 24/7 uptime = ∞ leverage
- Traditional cost: $10M+/year in salaries
- Agentic cost: $500/month in API + compute
